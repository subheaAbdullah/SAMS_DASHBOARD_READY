# SAMS Dashboard — Grant Monitoring + MEAL

لوحة متابعة المشاريع الإنسانية لمنظمة **Syrian American Medical Society (SAMS)**،
مع قسم جديد لمتابعة المشاريع (**MEAL**) وتقارير PDF / Word.

---

## 1) التشغيل

```bash
pip install -r requirements.txt
streamlit run ss_dash.py
```

ثم افتح: `http://localhost:8501`

> `ss_dash.py` هو نقطة التشغيل الرسمية. يمكنك أيضاً تشغيل `streamlit run app.py` كما كان سابقاً.

### الحسابات
- **الأدمن الأساسي:** `SAMSAD` / `lifesave`
- **المستخدم العادي:** يسجّل حساباً من تبويب «Create account»، وبعدها يستطيع المشاهدة والفلترة
  وتنزيل تقارير PDF / Word / Excel، لكنه **لا يعدّل** البيانات ولا يدير المستخدمين.
- يمكن للأدمن ترقية أي مستخدم إلى **Admin** من تبويب الصلاحيات.

---

## 2) قسم متابعة المشاريع (MEAL)

من **الصفحة الرئيسية** انزل إلى قسم:

> 📊 **Projects Follow-up (MEAL)** — الإنجاز الشهري · التقارير · الصلاحيات

ويحتوي على التبويبات التالية:

1. **📝 إدخال الإنجاز الشهري**
   - جدول `st.data_editor` قابل للتعديل والإضافة.
   - الحفظ في: `.sams_private/monthly_actuals.csv`
   - الأعمدة: الشهر، المشروع، المانح، المستوى، المؤشر، الهدف، الإنجاز، ملاحظة، آخر تعديل.
   - (الأدمن فقط يعدّل ويحفظ — المشاهد يرى الجدول فقط.)

2. **📊 المتابعة والتقارير**
   - فلترة حسب: الشهر / المشروع / المانح / المستوى.
   - مؤشرات فورية: الهدف، الإنجاز، نسبة الإنجاز، عدد المشاريع والمانحين.
   - رسوم: الهدف مقابل الإنجاز حسب المشروع، توزيع الإنجاز حسب المانح.
   - **تصدير Excel** جاهز (عدة أوراق: المتابعة، حسب المشروع، حسب المانح، حسب المستوى).
   - **تصدير PDF و Word** — متاح لكل المستخدمين المسجّلين.

3. **🔐 الصلاحيات (Users / Roles)**
   - الأدمن: إضافة مستخدم، تحديد الدور (Viewer / Admin)، تعديل الاسم،
     تغيير كلمة المرور، حذف مستخدم.
   - المشاهد: يرى قائمة الأدوار فقط (بدون إيميلات أو كلمات مرور).
   - الحسابات تُحفظ في: `.sams_private/users.json` (كلمات المرور مُشفّرة).

4. **🗓️ التقرير الشهري (أدمن فقط)**
   - اختيار الشهر.
   - **أرقام**: الهدف/الإنجاز/نسبة الإنجاز + النتائج العامة (خدمات، مستفيدون، منشآت، محافظات، برامج).
   - **صور**: رسوم PNG جاهزة (حسب المشروع/المانح/المحافظة + الاتجاه الشهري).
   - **تنزيل**: PDF، Word، Excel، وصور ZIP.
   - النتائج العامة تُحسب تلقائياً من قاعدة البيانات الرئيسية للشهر المختار.

## 3) الخصوصية — البيانات لا تُرفع على GitHub

كل ما هو حسّاس يُخزَّن داخل مجلد خاص:

```
.sams_private/
├── data.xlsx               ← نسخة البيانات الدائمة (اختيارية)
├── users.json              ← الحسابات
├── monthly_actuals.csv     ← الإنجاز الشهري
└── uploads/
```

وهذا المجلد **مستثنى** في `.gitignore`، بالإضافة إلى:

- `*.xlsx` / `*.xls` / `*.csv` / `*.pkl`
- `saves/` (ملفات المنح المحفوظة)
- `crm/` (جداول CRM)
- `users.json` / `monthly_actuals.csv`

### تنزيل البيانات (أدمن فقط)
من قسم MEAL افتح: **🔐 Data tools (admin only)** ثم:
- تنزيل قاعدة البيانات كاملة (Excel / CSV).
- تنزيل `monthly_actuals.csv`.

### حفظ ملف بيانات بشكل دائم
1. من الشريط الجانبي افتح **Data Source**.
2. ارفع ملف Excel (أدمن).
3. اضغط **💾 Save permanently** — يُحفظ في `.sams_private/data.xlsx`.
4. لإلغاء النسخة الدائمة: من **Data tools** اضغط حذف الملف الدائم.

> ⚠️ إذا كانت البيانات قد رُفعت سابقاً إلى GitHub، احذفها من تاريخ Git أيضاً
> (وليس من آخر commit فقط) ثم اعمل force-push. راجع القسم التالي.

---

## 4) رفع التعديلات على GitHub بأمان

```bash
# تأكد أن البيانات غير مضافة
git status

# أضف الكود فقط (البيانات مستثناة تلقائياً)
git add .gitignore app.py sams_meal.py ss_dash.py requirements.txt README_AR.md
git commit -m "MEAL section, private storage, PDF/Word reports, performance caching"
git push origin main
```

إذا كانت ملفات البيانات موجودة في تاريخ Git القديم، نظّف التاريخ مرة واحدة:

```bash
# (احتياط: خذ نسخة من المشروع أولاً)
git filter-branch --force --index-filter \
  'git rm -r --cached --ignore-unmatch -- "*.xlsx" "*.xls" "*.csv" "*.pkl" "saves" "crm" "users.json" "monthly_actuals.csv"' \
  --prune-empty --tag-name-filter cat -- --all

git push --force origin main
```

> GitHub قد يحتفظ بالكائنات القديمة مؤقتاً. للحذف النهائي اطلب من دعم GitHub
> purge للـ repository، أو احذف الـ repository وأعد إنشاءه من النسخة النظيفة.

## 5) تحسينات الأداء (خفّة على البيانات)

- `st.cache_data` لقراءة Excel وتنظيفه.
- كاش لأعمدة كل زر (`_match_cols_cached`).
- كاش لحساب «هل يوجد بيانات» لكل بطاقة (`_hhs_has_data`).
- كاش لعدّ المنشآت حسب النوع — بدل إعادة حسابها عشرات المرات في كل رسم.
- بصمة ذكية للـ DataFrame تُحسب مرة واحدة في كل إعادة تشغيل.
- كاش لملف الإنجاز الشهري (يتجدد تلقائياً عند الحفظ).
- كاش لتقارير PDF/Word/Excel المولّدة.
